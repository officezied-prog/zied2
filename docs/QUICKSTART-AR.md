# دليل تشغيل منصة رابط — خطوة بخطوة

هذا الدليل يشرح كيف تشغّل المنصة على جهازك من الصفر. اتبع المراحل بالترتيب.

---

## المرحلة ٠ · تجهيز الجهاز

تحتاج إلى أداتين فقط:

**أولًا: بيئة تشغيل جافاسكربت، الإصدار العشرون أو أحدث.** حمّلها من:

```
https://nodejs.org
```

للتأكد أنها مثبّتة، افتح نافذة الأوامر واكتب:

```bash
node -v
npm -v
```

يجب أن يظهر رقم يبدأ بـ

```
v20
```

أو أعلى. إن ظهر خطأ، فالتثبيت لم ينجح بعد.

**ثانيًا: أداة إدارة الإصدارات.** حمّلها من:

```
https://git-scm.com
```

للتأكد:

```bash
git --version
```

## المرحلة ١ · تحميل المشروع

في نافذة الأوامر، انتقل إلى المجلد الذي تريد العمل فيه، ثم:

```bash
git clone https://github.com/officezied-prog/zied2.git
cd zied2
git checkout claude/influencer-brand-coordination-app-n68uyw
```

السطر الأخير مهم: كل العمل موجود على هذا الفرع، وليس على الفرع الرئيسي.

## المرحلة ٢ · ملف الإعدادات

انسخ ملف الإعدادات النموذجي إلى ملف إعدادات حقيقي.

على نظام ماك أو لينكس:

```bash
cp .env.example .env
```

على ويندوز داخل موجّه الأوامر:

```bat
copy .env.example .env
```

الآن افتح الملف المسمّى:

```
.env
```

بأي محرّر نصوص، وضع مفتاح كلود في السطر المخصّص له:

```bash
ANTHROPIC_API_KEY=sk-ant-...ضع-مفتاحك-هنا
```

تحصل على المفتاح من لوحة تحكّم أنثروبيك:

```
https://console.anthropic.com/settings/keys
```

**ملاحظة مهمة:** لست مضطرًا لوضع المفتاح الآن. إن تركته فارغًا، ستعمل المنصة بالكامل في وضع بلا اتصال: نفس البيانات، نفس الأزرار، ونفس الخوارزميات، لكن عقل الوكلاء يعمل بقواعد ثابتة بدل الذكاء الاصطناعي. أضف المفتاح متى شئت وأعد التشغيل.

لا ترفع الملف

```
.env
```

إلى المستودع أبدًا — هو مستثنى تلقائيًا لحماية مفتاحك.

## المرحلة ٣ · تثبيت الحزم والتشغيل

من داخل مجلد المشروع:

```bash
npm install
npm run dev
```

التثبيت يستغرق ثوانٍ معدودة ويحدث مرة واحدة فقط.

عند نجاح التشغيل تظهر رسالة تخبرك بحالة النظام كاملة:

```
Rabith API  → http://localhost:8787/api
Brain       → Claude claude-opus-5
Hands (n8n) → not configured (N8N_WEBHOOK_BASE)
Config      → /path/to/zied2/.env
Accounts    → sign-in optional (open demo mode)
              seeded 3 accounts — admin: admin@rabith.id
```

اقرأ السطر الثاني للتأكد:

- إذا ظهر اسم النموذج، فالمفتاح يعمل والعقل متصل.
- إذا ظهرت كلمة

```
OFFLINE
```

فالمفتاح غير موجود أو غير صحيح، والمنصة تعمل بوضع القواعد.

الآن افتح المتصفح على العنوان:

```
http://localhost:8787
```

لإيقاف الخادم، اضغط في نافذة الأوامر على:

```
Ctrl + C
```

## المرحلة ٤ · الحسابات وتسجيل الدخول

زر تسجيل الدخول موجود أعلى يسار الشاشة. عند أول تشغيل تُنشأ ثلاثة حسابات تجريبية تلقائيًا لتجرّب الأدوار الثلاثة فورًا:

| البريد | كلمة المرور | الدور | ما يراه |
|---|---|---|---|
| `admin@rabith.id` | `rabith-admin` | مسؤول المنصة (أنت وفريقك) | كل الصفحات، غرفة العمليات، وإدارة المستخدمين |
| `brand@rabith.id` | `rabith-brand` | شركة | علامتها وحملاتها فقط — لا ترى الوكلاء |
| `creator@rabith.id` | `rabith-creator` | صانع محتوى | صفحته والعقود والأسعار فقط |

داخل نافذة الدخول زر يملأ بيانات المسؤول بضغطة واحدة.

**مهم للأمان:** غيّر كلمات المرور هذه قبل أي استخدام حقيقي. الطريقة الأسهل: ضع كلمة مرور قوية في ملف الإعدادات قبل أول تشغيل:

```bash
RABITH_ADMIN_EMAIL=you@yourdomain.com
RABITH_ADMIN_PASSWORD=كلمة-مرور-قوية-وطويلة
```

أو غيّرها بعد الدخول من لوحة الحساب. رسالة البدء تنبّهك ما دامت كلمات المرور التجريبية مستعملة.

### إنشاء حساب جديد

من نافذة الدخول اختر التبويب الثاني، ثم اختر نوع الحساب:

- **شركة أو علامة تجارية:** يُنشأ لها سجلّ تلقائيًا في لوحة إدارة العلاقات بمرحلة عميل محتمل، فتصل تسجيلات الموقع إلى مسار المبيعات مباشرة.
- **صانع محتوى:** يُربط بملفه إن تطابق اسم حسابه مع ملف موجود في قاعدة المؤثرين.

### إضافة حسابات لفريقك

فريقك = الحسابات ذات دور **مسؤول المنصة**. هي وحدها التي ترى غرفة العمليات.

**الطريقة الأولى · من التطبيق.** سجّل الدخول بحسابك، اضغط اسمك في الأعلى، ثم زر إضافة مستخدم. اكتب الاسم والبريد، اضغط زر التوليد لكلمة مرور قوية، واختر الدور الأول. بعد الحفظ تظهر لك نافذة فيها البيانات كاملة مع زر نسخ — سلّمها لزميلك عبر قناة خاصة. لن تظهر كلمة المرور بعدها.

**الطريقة الثانية · من سطر الأوامر.** أسرع، وتصلح للخادم قبل أن تفتح المتصفح أصلًا:

```bash
npm run user -- add teammate@yourdomain.com --name "اسم الزميل" --role admin
```

تُولَّد كلمة مرور قوية وتُطبع مرة واحدة. ولو أردت تحديدها بنفسك:

```bash
npm run user -- add teammate@yourdomain.com --name "اسم الزميل" --role admin --password "كلمة-مرور-قوية"
```

أوامر أخرى:

```bash
npm run user -- list
npm run user -- promote someone@yourdomain.com --role admin
npm run user -- password someone@yourdomain.com
npm run user -- suspend someone@yourdomain.com
npm run user -- activate someone@yourdomain.com
npm run user -- delete someone@yourdomain.com
```

الترقية مفيدة إذا سجّل زميلك بنفسه كشركة ثم أردت ضمّه للفريق. وإعادة التعيين تُخرج حسابه من كل الأجهزة فورًا.

هذه الأوامر تعمل والخادم يعمل: يلتقط التغيير خلال ثوانٍ بلا إعادة تشغيل.

**تنبيه:** الحسابات تعيش في قاعدة بياناتك المحلّية، لا في المستودع. كل خادم تشغّله له حساباته الخاصة.

### لوحة الحساب

اضغط على اسمك في الأعلى لتفتح لوحة الحساب. منها تعدّل اسمك ولغتك، تغيّر كلمة المرور، وتنهي الجلسات على الأجهزة الأخرى. وإذا كنت مسؤولًا، تظهر لك قائمة المستخدمين: تغيير الدور، تعليق الحساب، إعادة تعيين كلمة المرور، أو الحذف.

### إلزام تسجيل الدخول

المنصة تعمل افتراضيًا بلا تسجيل دخول ليسهل استعراضها. عندما تجهّزها لعملاء حقيقيين، فعّل الإلزام في ملف الإعدادات:

```bash
RABITH_AUTH_REQUIRED=1
```

عندها يصبح كل تعديل أو إنشاء محتاجًا إلى حساب، بينما تبقى القراءة ونداءات محرّك الأتمتة تعمل كما هي.

## المرحلة ٥ · جولة في التطبيق

هذه أسرع طريقة للتأكد أن كل شيء يعمل. جرّب بالترتيب:

**١. اكتشف.** صفحة البحث عن المؤثرين. جرّب الفلاتر: المنصة، النيش، الفئة، المدينة، ثم حرّك مؤشر «أقصى احتيال» إلى الرقم عشرين وشاهد كيف تختفي الحسابات المشبوهة. اضغط أي بطاقة ثم زر فحص الاحتيال لترى الإشارات الست وتفسيرها.

**٢. العلامات.** لوحة إدارة العلاقات. اسحب أي بطاقة بين المراحل، أو استخدم السهمين. اضغط البطاقة لفتح ملف الشركة، ومنه يمكنك توليد رسالة تواصل أو إنشاء حملة أو سؤال المنسّق مباشرة.

**٣. الحملات.** اضغط «حملة جديدة»، املأ الميزانية والنيش والمدينة، ثم احفظ. تعمل المطابقة تلقائيًا وتظهر لك خمس وعشرون نتيجة مرتبة، مع تفصيل الدرجة بثمانية عوامل وخطة محسّنة للميزانية. يمكنك تصدير النتائج كملف جدول.

**٤. التواصل.** اختر شركة وقالبًا، ثم «توليد المعاينة». القوالب مأخوذة من ملفك الأصلي بثلاث لغات. فعّل خيار التخصيص بالذكاء الاصطناعي إن كان المفتاح موجودًا.

**٥. غرفة العمليات.** لا تظهر إلا بعد تسجيل الدخول بحساب مسؤول، ولا يراها العملاء إطلاقًا. اكتب طلبك للمنسّق، أو اضغط أحد الاقتراحات الجاهزة مثل: ابحث عن عشرين مؤثر نانو للتجميل في جاكرتا. سترى خطة المنسّق، ثم خط زمني لكل وكيل فُوّض إليه، ثم الإجابة الموحّدة. ولبناء وكلائك أنت، اقرأ الدليل المخصّص: `docs/AGENTS-AR.md`.

**٦. السوشيال.** مُحرّر المنشورات مع توليد بالذكاء الاصطناعي، جدولة، وتقويم شهري.

**٧. العقود.** يولّد عقدًا إندونيسيًا مكتملًا من بيانات الحملة والمؤثر، مع حساب الرسوم والضرائب والضمان، وزر طباعة.

## المرحلة ٦ · تشغيل محرّك الأتمتة

هذه المرحلة اختيارية. المنصة تعمل بدونها، لكن أزرار الإرسال والنشر ستحفظ العمل كمجدول بدل تنفيذه فعليًا.

المحرّك اسمه:

```
n8n
```

وهو المسؤول عن التنفيذ الخارجي: إرسال البريد والواتساب، النشر على الشبكات، وجدولة المتابعات.

### الطريقة الأولى: عبر الحاويات (موصى بها)

تحتاج إلى تثبيت:

```
Docker Desktop
```

من الموقع:

```
https://www.docker.com/products/docker-desktop
```

ثم من داخل مجلد المشروع نفّذ أمرًا واحدًا:

```bash
docker compose up --build
```

هذا يشغّل الخدمتين معًا: المنصة على المنفذ

```
8787
```

ومحرّك الأتمتة على المنفذ

```
5678
```

### الطريقة الثانية: بدون حاويات

في نافذة أوامر ثانية، ومع بقاء المنصة تعمل في النافذة الأولى:

```bash
npx n8n
```

ثم افتح:

```
http://localhost:5678
```

وأنشئ حسابك المحلي.

### استيراد سير العمل

بعد فتح لوحة المحرّك:

1. اضغط القائمة العلوية ثم خيار الاستيراد من ملف.
2. اختر الملفات السبعة الموجودة في مجلد:

```
n8n/workflows/
```

3. كرّر العملية لكل ملف، ثم فعّل كل سير عمل من المفتاح العلوي.

### ربط المحرّك بالمنصة

في ملف الإعدادات الخاص بالمنصة، أزل التعليق عن هذين السطرين وتأكد من قيمتهما:

```bash
N8N_WEBHOOK_BASE=http://localhost:5678/webhook
RABITH_WEBHOOK_SECRET=ضع-هنا-كلمة-سر-طويلة-تخترعها
```

نفس كلمة السر يجب أن تُضبط داخل المحرّك كمتغيّر بيئة باسم:

```
RABITH_WEBHOOK_SECRET
```

هي التي تمنع أي جهة خارجية من مناداة المنصة أو المحرّك.

أعد تشغيل المنصة بعد التعديل. يجب أن يتغيّر السطر الثالث من رسالة البدء ليعرض عنوان المحرّك بدل عبارة غير مُعدّ.

### بيانات اعتماد القنوات

كل قناة تحتاج إلى ربط حسابها داخل المحرّك نفسه، لا داخل المنصة:

- البريد عبر حساب جوجل.
- الواتساب عبر واجهة الأعمال السحابية من ميتا.
- إنستغرام وفيسبوك عبر واجهة ميتا للرسم البياني.
- لينكدإن وتيك توك ومنصة إكس عبر مفاتيحها الخاصة.

التفاصيل الكاملة لكل قناة موجودة في الملف:

```
n8n/README.md
```

## حل المشاكل الشائعة

**المنفذ مشغول.** إذا ظهرت رسالة تفيد أن العنوان قيد الاستخدام، غيّر رقم المنفذ في ملف الإعدادات:

```bash
PORT=8080
```

أو أوقف العملية القديمة.

**المفتاح لا يُقرأ.** تأكد أن اسم الملف هو

```
.env
```

بنقطة في أوله وبلا أي امتداد آخر. ويندوز أحيانًا يضيف امتدادًا مخفيًا. راجع السطر الرابع من رسالة البدء: يعرض لك المسار الكامل للملف الذي قُرئ فعلًا.

**النموذج لا يستجيب.** راجع رصيد حسابك في لوحة أنثروبيك، ثم جرّب سؤال المنسّق مرة أخرى. عند فشل الاتصال تظهر رسالة الخطأ داخل المحادثة نفسها.

**أريد إعادة البيانات إلى حالتها الأولى.** احذف ملف قاعدة البيانات المحلي:

```bash
rm apps/api/data/db.json
```

ثم أعد التشغيل. ستُبنى البيانات من جديد: مئة وعشرون مؤثرًا وست وعشرون شركة.

**نسيت كلمة مرور المسؤول.** أوقف الخادم، احذف حساب المسؤول من ملف قاعدة البيانات، أو ابدأ من قاعدة بيانات جديدة بعد ضبط كلمة المرور في ملف الإعدادات:

```bash
RABITH_ADMIN_PASSWORD=كلمة-مرور-جديدة
```

الحسابات لا تُمسح عند إعادة بناء البيانات التجريبية، لذا احذف الملف بالكامل إن أردت بداية نظيفة.

**الصفحة تظهر لكن بلا بيانات.** افتح أدوات المطوّر في المتصفح وراجع تبويب الشبكة. إن كانت كل الطلبات فاشلة، فالخادم متوقف. أعد تشغيل الأمر:

```bash
npm run dev
```

**فتحت الملف مباشرة بالنقر المزدوج.** في هذه الحالة يعمل التطبيق في وضع تجريبي من الذاكرة المحلية فقط. للحصول على الوظائف الكاملة، شغّل الخادم وافتح العنوان:

```
http://localhost:8787
```
